# Kindred: Lovable project kit

"Volunteer once. Qualify everywhere." A marketplace where charities and volunteers find each other, with portable training credentials.

| File | Where it goes |
|---|---|
| `1_PROJECT_KNOWLEDGE.md` | Lovable → Project Settings → Knowledge (paste all of it) |
| `2_FIRST_PROMPT.md` | Lovable chat, **Plan** mode. The first message. |
| `3_BUILD_PROMPTS.md` | Lovable chat, **Agent** mode, one step at a time |
| `4_TEAM_HANDOVER.md` | Share with the team: roles, timeline, the one-prompter rule |
| `AGENTS.md` | Commit to the root of the Lovable GitHub repo (same rules; Lovable reads it on every request) |

Order: Knowledge → First prompt (Plan) → approve → Build prompts (Agent) → Security scan → Publish.
