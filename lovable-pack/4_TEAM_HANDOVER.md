# Team handover: 4 people, 1 shared Lovable project

## Golden rule
**Only one person sends a prompt to Lovable at a time.** Prompts that run at the same time overwrite each other. Call "I'm prompting" / "done" in the group chat. Everyone else works OFF Lovable in parallel (content, QA, pitch) and hands the driver ready-to-paste prompts.

## Roles
| Person | Role | Does |
|---|---|---|
| A | **Driver** | The only one who prompts Lovable for the first ~90 min (Knowledge → plan → foundation → features 1–4). Bookmarks every working version in History. |
| B | **Content + data** | Writes the seed content as text and pastes it to A: 5 training modules (3 short lessons + 5 quiz Qs each), 6 org bios, 30 shift titles/descriptions, Maya's & Alex's profiles, the coordinator's welcome chat message. |
| C | **QA + security** | Tests every finished step in the preview (incognito, mobile width, dark mode, logged out, as the other demo user). Logs bugs as one-line, ready-to-paste fix prompts. Runs the Security pass + scan before publishing. |
| D | **Pitch + demo** | Writes DEMO.md (hook 10s → moment 40s → why it's real 10s → ask 10s), a 3–5 slide deck, and market proof points (volunteer drop-off stats, onboarding time at large charities). Rehearses the click path. Owns the timer. |

After the foundation is built, the driver role can rotate **per feature**. Hand over only between prompts, never mid-run.

## Timeline (adjust to the event)
- **0:00–0:15** A: paste Knowledge, then the first prompt in Plan mode; the team reads the plan and A approves it. B, C and D start their tracks.
- **0:15–1:30** A: Foundation, then Marketplace, Training → credential, Booking (B's content gets pasted in as it's ready).
- **1:30–3:00** Rotate driver: Chat, Charity dashboard, AI matchmaker, Admin. C files fixes between features.
- **3:00–** Demo-proofing, Security pass, Polish. **Freeze 60 min before demos**: demo-path bugs only.
